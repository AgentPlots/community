# AgentPlots Community

Public space for AgentPlots users: questions, ideas, bug reports and announcements.

## Where to go

| I want to… | Go to |
|---|---|
| Ask a question | [Discussions → Q&A](https://github.com/AgentPlots/community/discussions/categories/q-a) |
| Suggest a feature | [Discussions → Ideas](https://github.com/AgentPlots/community/discussions/categories/ideas) |
| Report a bug | [Issues](https://github.com/AgentPlots/community/issues/new) |
| Read news and release notes | [Discussions → Announcements](https://github.com/AgentPlots/community/discussions/categories/announcements) |

## Reporting a bug

Please include:

- AgentPlots version
- Operating system
- Steps to reproduce
- What you expected and what happened instead

## Security

Do not report security vulnerabilities in public issues or discussions.
Send them privately to **support@agentplots.com**.

## Contact

- Support: support@agentplots.com
- Community: community@agentplots.com

## Rules

Be respectful, stay on topic, and do not post passwords, license keys or other private data.
